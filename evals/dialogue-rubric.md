# 需求引导对话评测

用于评估 Skill 是否能把不同清晰度的用户引导到可确认首版。评测对象是实际对话行为，不是文档是否存在。

## 执行方式

1. 在目标宿主中使用同一版本的 `SKILL.md` 和需求发现参考文件。
2. 按 `evals/cases/discovery-*.json` 逐条输入初始请求和后续回复，不额外补充答案。
3. 保存完整对话、首个工作流卡片、输出样例和最终状态。
4. 对照每个 case 的 `expected_behavior` 与 `critical_failures` 评分。

## 评分

每条预期行为记为通过 / 失败 / 不适用，并附对话证据。任何 critical failure 出现，则该用例失败，不能用其他平均分抵消。

同时记录：

- 首个可确认工作流卡片所需轮次；
- 重复提问次数；
- 未标注假设或默认建议的数量；
- 是否过早选择平台或生成完整 SOP；
- 是否提供输出样例确认；
- 目标变化后是否正确保留有效结论并重新确认风险。

“回复听起来自然”不能替代行为证据。单次通过只代表该宿主、该版本和该输入的一次冒烟结果，不代表跨宿主或稳定复用已验证。

## 结果记录

在 `evals/results/` 中保存：日期、宿主、可获得的配置、Skill 版本或提交、用例、逐项结果、问题摘录、修订动作和未验证范围。真实用户材料需要授权和脱敏；合成对话必须明确标注。
